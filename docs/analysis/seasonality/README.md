# Сезонность, снег, погода — почему не признаки

**Вопрос.** Нужны ли снежный покров, погода, длина дня, сезонность ночной яркости?

**Ответ: нет.** Запись: `EXPERIMENTS.md` →
«2026-09-15 - Сезонность, снег и погода: проверка перед добавлением признаков».

**Довод 1 — цель не меняется по сезонам пространственно.** Spearman счётчиков ДТП
по ячейкам, подвыборки равного размера: половина зимы vs половина лета **0.418**,
две половины лета 0.450, две половины зимы 0.478. Зимой аварии там же, где летом.

**Довод 2 — городская переменная коллинеарна календарю.** Снег/погода одинаковы для
всех 4 296 ячеек в месяце → одна степень свободы на месяц → строго коллинеарно
`month_num`. А календарь уже проверен: удаление `year`+`month_num` дало
top-1% precision **+0.0000** ровно (запись 2026-06-09).

**Довод 3 — описательно.** Снег/лёд — 6.3% ДТП за 11 лет; зима — низкий сезон
(февраль 1 007 против октября 1 611); на снегу погибших **2.48%** против 4.91% на
мокром и 4.03% на сухом — «видимая опасность безопаснее невидимой».

**Общий вывод двух разборов (день/ночь и зима/лето):** пространственное распределение
риска в Саратове устойчиво к условиям. Признак обязан различать **места**, а не
**условия**. Это и привело к уклону (`../terrain/`).
