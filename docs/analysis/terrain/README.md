# Продольный уклон дорог (Copernicus DEM) — в кассу

**Вопрос.** Даёт ли уклон дорог прирост road-only 4.0? Это первый признак,
выбранный по критерию «различает места, а не условия».

**Ответ: да, в верхе ранжирования.** Запись: `EXPERIMENTS.md` →
«2026-09-16 - Road-Only 4.0 + продольный уклон дорог (Copernicus DEM)» (там же EDA).

| метрика | road-only 4.0 (59) | + уклон (65) | Δ | вердикт |
|---|---|---|---|---|
| ROC-AUC | 0.907826 | 0.907765 | −0.00006 | шум |
| PR-AUC | 0.199075 | 0.199672 | +0.0006 | шум |
| **precision@1%** | 0.3025 | **0.3128** | **+0.0103** | значимо |
| recall@1% | 0.1295 | 0.1339 | +0.0044 | значимо |
| recall@5% | 0.4414 | 0.4441 | +0.0027 | значимо |

Площади под кривыми не сдвинулись; верх списка — операционная метрика — стал точнее
и устойчивее (разброс по сидам втрое меньше). Уклон — 5-е место по важности, и в
отличие от VIIRS (1-е место, нулевой прирост) он добавляет информацию.

**Ключевой факт из EDA — уклон действует только при наличии экспозиции.** Частота
ДТП по уклону внутри терцилей длины дорог: в малодорожных ячейках ряд плоский
(~0.3%); в плотных — рост 1.93 → **7.91%** от 0–1% к 3–5%, затем спад. Это форма
`N_SPF(AADT) × CMF` из HSM / произведения коэффициентов Бабкова, полученная из данных.

**Источник.** Copernicus DEM GLO-30, 30 м, глобальный, открыт на AWS без регистрации,
27–29 МБ на тайл. Здания при 30 м не разрешаются (застроенная пойма 3.5% против поля
4.0%) — FABDEM не нужен. Уклон считается **вдоль дорог** (OSM, шаг 20 м, окно 200 м);
окно выбрано по замеру шума DEM на заведомо плоской пойме.

**Из шести признаков оставлены два** (см. выводы EDA в журнале):
`road_grade_abs_mean_weighted`, `grade_change_density_per_km`. С 2026-09-16 они входят в
**бейзлайн проекта** — feature set `road_geo_baseline`, 61 признак; запись «Road+Geo Baseline».
