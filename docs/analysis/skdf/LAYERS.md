## Грабли (повтор из METHODOLOGY.md, раздел 6)

`bbox=` игнорируется → `CQL_FILTER=BBOX(geom,…,'EPSG:4326')` для паспортных слоёв,
сырой Web Mercator без CRS — для инженерных (`lyr_eng_*`); `startIndex` требует `sortBy`;
геометрия участка возвращается целиком (Р-228 на 600 км) — резать по рамке; `region_gid`
не код субъекта; массивные поля (`weather_cond_gid` и т.п.) приходят строкой
`[Ljava.lang.Long;@…` — не десериализованы на стороне сервера.

## Что заводить в модель следующим

1. `road_normative_condition` → флаг «не в нормативе» (2 849 участков) — прямой сигнал состояния.
2. `roadway_width`, `coating` (4 типа), `axle_load` — паспортная физика, которой в OSM нет.
3. `category_snip` — категория улицы по СП как альтернатива `highway=*`.
4. `diag_hwd_eveness` → доля длины с нарушением ровности (8 621 отрезок — единственная
   диагностика с городским охватом); `clutch` → K₁₆, но только фед./рег.
5. `traffic` → `skdf_veh_km` по региональным/федеральным, где числа настоящие.
