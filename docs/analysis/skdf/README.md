# ФГИС СКДФ — открытый реестр дорог

**Полный инвентарь слоёв и что из них брать: [`LAYERS.md`](LAYERS.md).**

**Что это.** Федеральная система контроля дорожных фондов; открытый WFS
`https://скдф.рф/api-geoserver/skdf_open/wfs`, 259 слоёв, 1.94 млн участков по РФ,
без авторизации. Полный разбор: `../../../METHODOLOGY.md`, раздел 6.

**Что брать.** Паспортные атрибуты, где OSM пуст: разрешённая скорость (97% против
7% в OSM), полосность (98% против 12%), покрытие (99.7%), **ширина проезжей части**
(94.5%, в OSM нет), категория по СНиП. Слои диагностики (сцепление, колея) — только
фед./рег. дороги.

**Что с оговорками.** Поле `traffic` — не измерения, а задекларированное значение
паспорта: 91 уникальное значение на 5 094 участка, у половины ровно 380 (заглушка).
На магистралях правдоподобно, на местных улицах — нет.

**Грабли.** `bbox=` игнорируется → только `CQL_FILTER=BBOX(geom,…,'EPSG:4326')`;
инженерные слои требуют сырой Web Mercator; `startIndex` без `sortBy` → 400;
`region_gid` — не код субъекта; геометрия участка возвращается целиком (Р-228 на 600 км) — резать по рамке.

Скрипт: `scripts/fetch_skdf_traffic.py`. Данные: `parquet_output/skdf_traffic_saratov.geojson`.
В модель пока не заведено.

**EDA (2026-09-16, запись «EDA по данным ФГИС СКДФ» в журнале).** Заглушка 380 —
на 74.6 % местных дорог и 0 % региональных/федеральных; настоящие числа у 1 685
участков (категории IБ–IV), монотонно по категории. Ширина на полосу — 3.50 м
(норма). Полосность с OSM почти не согласуется (Spearman 0.18) — не смешивать.
Агрегаты в ячейки: `parquet_output/h3_skdf_features.parquet`.
