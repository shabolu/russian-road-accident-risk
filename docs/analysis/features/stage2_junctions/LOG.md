## 2. Построение узлов с истинной степенью (00:55–00:57)

Код — **новые** функции в `src/road_accident_risk/osm_road_features.py` (старые
`build_graph_node_stats` и `scripts/build_road_graph_nodes.py` не тронуты, viewer и
признаки бейзлайна не меняются):
- `STREET_ROAD_CLASSES = MOTOR_ROAD_CLASSES − {service}` (уличная сеть);
- `build_junction_v2_node_stats(roads, signal_points)` — по `osm_roads_raw.parquet`:
  для каждого вхождения узла в way подход даёт каждое соседнее ребро (интерьерная
  вершина — 2, концевая — 1, точка замыкания замкнутого way — 2; повтор вершины подряд
  не считается). Степень считается отдельно по полной сети (`degree_full`), уличной
  (`degree_street`) и по service (`degree_service`). В таблицу попадают узлы, общие для
  ≥ 2 ways, или с ≥ 3 подходами; признак «смена имени» не используется вовсе.
  Светофор — `highway=traffic_signals` в радиусе 30 м (`TRAFFIC_SIGNAL_RADIUS_M`),
  поиск через `scipy.spatial.cKDTree` + проверка haversine (та же метрика, что в старом коде).
  Угол: азимут на точку в 20 м вдоль каждого уличного подхода (`_probe_point`);
  `junction_angle_deviation` = min |θ − 90°| по углам между соседними по азимуту подходами.
- `aggregate_h3_junction_v2_features(nodes, cells)` — счёт на ячейку; нет узлов → 0,
  у `junction_angle_dev_mean` нет уличных перекрёстков → NaN (это не «прямой угол»).

Определения узлов (уличная сеть):
| тип | условие |
|---|---|
| уличный перекрёсток | `degree_street ≥ 3` |
| 3-сторонний / 4-сторонний | `degree_street = 3` / `≥ 4` |
| со светофором | уличный перекрёсток и светофор ≤ 30 м |
| магистраль × улица без светофора | уличный перекрёсток, среди уличных классов есть major и не-major, светофора нет |
| въезд (driveway) | `degree_street ≥ 2` и `degree_service ≥ 1`: service ответвляется от проходящей улицы |
| `street_class_delta` | max − min ранга `ROAD_CLASS_RANK` среди уличных классов узла (service исключён); только у уличных перекрёстков |

Решение по въезду: требую `degree_street ≥ 2` (улица проходит через узел). Узел «улица
кончается и продолжается service» (street 1 + service 1, степень 2) — это смена класса
линии, а не примыкание; в въезды не идёт.

Скрипт: `scripts/build_junction_v2_features.py` (1.6 с) →
`parquet_output/osm_junction_v2_nodes.parquet` (37 301 узел) и
`parquet_output/h3_junction_v2_features.parquet` (4 886 ячеек, как в `h3_road_features`).
Новые пути — `OSM_JUNCTION_V2_NODES_PARQUET`, `H3_JUNCTION_V2_FEATURES_PARQUET` в `paths.py`.

Итог по городу: уличных перекрёстков 8 102 (3-сторонних 6 456, 4+-сторонних 1 646, из
них 12 пятисторонних), въездов service → улица 10 279, светофор рядом у 358 уличных перекрёстков.

### 5.5. Решения по правилу «одна величина — один признак»

1. `street_junction_4leg_unsignalized_count` **исключён** (ρ 0.949 с
   `street_junction_4leg_count`; светофор есть лишь у 6 % крестов, так что это почти
   одна величина). Оставлен общий счёт крестов: выше одиночный AUC (0.696 против 0.629),
   а регулирование несёт отдельный `signalized_junction_count`. Альтернатива проверяется
   отдельным вариантом `junctions_alt_4leg_unsig`.
2. `junction_angle_dev_mean` оставлен для абляции: по ρ ни с чем не дублируется
   (max |ρ| 0.29), но слабый (AUC 0.57) и NaN в 55 % ячеек. Проверяется вариантом
   `junctions_no_angle`.
3. Пары новых признаков со старыми (0.953, 0.941) не мешают варианту B (старые там
   удалены). В варианте C они сознательно остаются — его задача как раз показать,
   есть ли в новых информация сверх старых.

Итог: в набор B входят **7 новых** признаков вместо 8 старых → 33 − 8 + 7 = **32**.

- recall@10 % «на границе» в пользу B и C — единственный намёк на эффект; парная оценка
  его не подтверждает. Формулировка для текста: «без ухудшения».

## 7. Дополнительные варианты (01:31–01:37)

```text
PYTHONPATH=src venv/bin/python scripts/run_road_geo_v2_junctions_experiments.py \
  --variants junctions_alt_4leg_unsig,junctions_no_angle
```

- B′ `junctions_alt_4leg_unsig` (32; 4-сторонние без светофора вместо всех 4-сторонних):
  к A и к B — шум по всем метрикам; к B precision@1 % +0.0034 (2σ 0.0031, «на границе»,
  парная 2·sd 0.0058 → шум). Выбор между двумя формами одной величины на метрики не влияет;
  оставлен общий счёт (выше одиночный AUC, светофор несёт `signalized_junction_count`).
- B″ `junctions_no_angle` (31): к A и к B — шум по всем метрикам (|Δ|/2σ ≤ 0.89 к A,
  ≤ 0.33 к B). При этом у угла в B важность 2.45 (ранг 19) — типичная картина для
  непрерывного признака с NaN: CatBoost охотно делает по нему разбиения, но качество от
  них не зависит. Решение: угол **остаётся** в наборе (дёшев, не дублирует ничего,
  мотивирован литературой), с пометкой «кандидат на удаление при фиксации, этап 7».
