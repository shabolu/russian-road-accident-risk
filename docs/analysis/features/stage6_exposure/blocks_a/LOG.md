## Правила выбора (зафиксированы ДО прогонов)

- выбор внутри блока по folds: больше средняя Δ PR-AUC к A; если разность вариантов < 2σ (по средним фолдов) —
  ничья: центр -> (б) POI (автоматический, переносим, PLAN 6.10); буфер -> ячейка (та же опора, что у остальных
  признаков); остановки -> старый счёт (заменять, только если новый лучше);
- блок проходит: средняя Δ по фолдам значима (≥ 1.5·2σ) по ROC-AUC или PR-AUC, знак этой метрики одинаков в
  обоих годах, precision@1 % и recall@10 % не падают сверх 2σ (по среднему фолдов);
- `pt_route_count` — последним: e4_routes = выбранный E4 + маршруты против выбранного E4.
