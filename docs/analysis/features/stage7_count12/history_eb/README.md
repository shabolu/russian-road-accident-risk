## 1. Модель против истории, «структура + история», EB

Варианты (все — в ДТП в год, прогноз на конец обучения):
- **модель** — Tweedie 1.3 на `road_geo_v2_skdf` (32), без истории;
- **история** — ДТП ячейки за прошлый год / за 3 года / в среднем за все прошлые годы обучения;
- **структура + история** — та же модель + лаги (`+lags`: прошлый год и 3 года; `+lags_all`: ещё «все годы»);
- **модель, кросс-фит** — прогноз ячейки от модели, обученной *без её группы ячеек* (5 групп по родителю H3 res 7,
  те же годы). Нужен потому, что обычная модель на обучении «помнит» ячейку (k на обучении 0.02 против 0.15 вне
  выборки, шаг 2A; у тяжёлых ячеек прогноз ≈ история: 24.4 против 66 × 3/8 = 24.75);
- **EB** — `w = 1/(1 + k·N_pred·T)`, `N_EB = w·N_pred + (1−w)·N_obs/T`; N_obs — ДТП за окно (3 года или все годы
  обучения: 6 / 7 / 8 лет), N_pred — модель (обычная или кросс-фит).

**Выводы.**
1. **Модель не обгоняет лучшую историю.** Против «ДТП за все прошлые годы» на фолдах — ноль, на тесте +0.5 п.п. в
   топ-10 % (ДИ накрывает 0) и +0.7 п.п. в топ-5 % (на границе значимости). Шаг 2A сравнивал модель с «3 годами» —
   над ними выигрыш есть (+2.7 п.п.), но «все годы» сильнее «3 лет» на 2.2 п.п. и закрывает почти весь этот выигрыш.
   По Spearman по всей сети история даже выше (0.72 против 0.69: «нет ДТП 8 лет → нет и сейчас»).
2. **Почему так: обычная «структурная» модель на годах обучения запоминает уровень ячейки.** 32 статичных
   признака почти однозначно определяют ячейку, 800 деревьев подгоняются к её среднему за 8 лет. Честная оценка
   чистой структуры — кросс-фит по ячейкам: 0.654 в топ-10 % на тесте и 0.655 на фолдах, то есть на 1.4–3.4 п.п.
   **хуже** истории за все годы. Для новой территории (без истории) ожидать нужно именно этот уровень.
3. **«Структура + история» почти ничего не даёт** (+0.3 п.п. к модели, ДИ накрывает 0): обычная модель уже
   содержит историю ячейки. Это верхняя граница «сколько добавляют лаги» — около нуля.
4. **EB поверх обычной модели бесполезен** (Δ −0.9…+0.3 п.п., шум): N_pred и N_obs несут одну и ту же
   информацию — история учтена дважды.
5. **Главный ответ этапа: честное сочетание структуры и истории лучше каждой части по отдельности, но
   ненамного.** EB(кросс-фит, все годы, k = 0.2): +2.5–3.8 п.п. к чистой структуре на фолдах и тесте (значимо);
   к истории за все годы — +1.0 / +1.2 п.п. на тесте (ДИ касаются 0) и 0 на фолдах. Лучшее значение теста —
   0.679 в топ-10 % (91 % потолка 0.746).

### Выбор k (`eb_k_grid.csv`, `eb_k_chosen.csv`, рис. 7)

Правило: максимум среднего топ-5 % и топ-10 % по двум фолдам среди k ∈ {0.1, 0.15, 0.2}.
- EB на обычной модели: **k = 0.1** (оба окна). Кривая по k почти плоская: от k = 0 (модель) до ∞ (история)
  топ-10 % меняется в пределах 0.689–0.692 на фолдах.
- EB на кросс-фите: **k = 0.2** (оба окна). По расширенной сетке фолды предпочли бы k = 0.5–1 (топ-10 % 0.692–0.695);
  на тесте плато 0.678–0.679 при k = 0.2–0.5. Т. е. честный N_pred заслуживает меньшего доверия, чем даёт
  оценка k ≈ 0.15 шага 2A (та оценка — вокруг обычной модели, которая сама уже содержит историю).
- При k = 0.2 и окне 8 лет вес модели у ячейки с N_pred = 2 ДТП в год — w = 1/(1 + 0.2·2·8) = 0.24; у ячейки с
  N_pred = 0.1 — 0.86.

Весь разброс 28 наборов на тесте: топ-10 % 0.671–0.677, топ-5 % 0.463–0.467, Spearman 0.682–0.687.

**Различимы ли наборы.** Нет.
- Сидовый 2σ на годовом таргете мал (0.001–0.003), поэтому многие Δ формально «значимы»: geometry − tags на
  фолдах +0.006 в топ-10 %, junctions → tags на тесте −0.004. Но парный бутстреп по ячейкам у **каждого** звена
  цепочки накрывает 0 и в топ-5 %, и в топ-10 %: медианная полуширина ДИ разности ±0.4 п.п. (топ-5 %) и
  ±0.6–0.7 п.п. (топ-10 %) против Δ 0.1–0.4 п.п. Различия наборов меньше неопределённости от того, какие ячейки
  попали в выборку.
- Spearman и отклонение различают наборы на тысячные (geometry − tags: Spearman −0.0017, отклонение +0.011 на
  тесте; skdf − geometry: +0.003 / −0.009) — направление то же, что в месячных выводах этапов 4–5 (геометрия
  слегка хуже тегов, СКДФ возвращает), но масштаб — тысячные доли.

**Совпадают ли выводы с месячными.** Месячные решения: этап 4 (геометрия хуже тегов, PR −0.0025, значимо),
этап 5 (СКДФ лучше геометрии, PR +0.0014, значимо), 6a (экспозиция = СКДФ), `geometry_plus_old` (+0.0017 PR,
значимо — «артефакт рисовки»). На годовом таргете по долям накрытых ДТП все эти Δ — шум; по Spearman и отклонению
знаки этапов 4 и 5 повторяются, у `geometry_plus_old` — тоже (Spearman +0.002, отклонение −0.011). Т. е. годовая
постановка **не опровергает** месячные решения, но и не делает их практически значимыми: ни один набор не меняет
долю накрытых ДТП больше чем на ±0.5 п.п.

## Абзац для курсовой

Годовая постановка позволила честно сравнить структурную модель с историей ДТП. Модель CatBoost (Tweedie,
32 признака улично-дорожной сети и паспорта СКДФ), обученная на 2015–2022 гг., отбирает 10 % ячеек, на которые
приходится 67 % ДТП 2023–2025 гг. и 94 % ячеек-очагов по аналогу критерия ОДМ (в верхних 5 % — 80 %). Однако
простое ранжирование по среднему числу ДТП за все прошлые годы даёт 66.8 % и 94 % — разница в пределах
случайной погрешности (бутстреп по ячейкам). Причина в том, что модель на годах обучения запоминает уровень
конкретной ячейки: если прогнозировать ячейку моделью, обученной без неё и её соседей, доля падает до 65.4 % —
это и есть вклад одной лишь структуры сети, ожидаемый для территории без статистики. Эмпирическое байесовское
сочетание такого «чистого» прогноза с историей ячейки (вес прогноза 1/(1 + k·N·T), k = 0.2) даёт 67.9 %:
значимо больше структуры и примерно на 1 п.п. больше истории. Перепроверка всех наборов признаков этапов 1–6
на годовом таргете показала, что они неразличимы: доля накрытых ДТП меняется в пределах 0.671–0.677 при
неопределённости разности ±0.6 п.п., а знак разностей на валидационных и тестовых годах для верхней части списка
совпадает хуже, чем случайно. Таким образом, информация признаков сети исчерпана на любом горизонте, а
крупнейшие ошибки прогноза связаны с изменениями во времени — снижением аварийности в бывших очагах и ростом в
новых кварталах, — которых статичные признаки не видят.

## Ограничения

- Бутстреп по ячейкам не учитывает пространственную корреляцию — ДИ, вероятно, уже истинных; тем более вывод
  «наборы неразличимы» устойчив, а «EB лучше истории на 1 п.п.» — нет.
- Кросс-фит по группам res 7 (≈ 49 ячеек res 9) оставляет в обучении более далёких соседей; полностью
  «новую территорию» (другой город) он не моделирует — это оценка сверху для переноса.
- k выбран из узкой сетки 0.1–0.2 по ТЗ; для EB на кросс-фите оптимум фолдов шире (0.5–1), тест к k в 0.2–0.5
  нечувствителен.
- EB использует N_pred без поправки на уровень года; на ранжирование это влияет слабо (поправка — общий множитель
  для N_pred, но не для N_obs), для PSI (этап 9) поправка обязательна.
- Месячные согласия знаков пересчитаны одним способом для месяца и года и расходятся с числами README 6a для
  p@1 (11 против 5 из 15) — вероятно, другая база на тесте; вывод о годе от этого не зависит.
- Spearman и отклонение у ориентиров-историй несравнимы с моделью напрямую (нули истории; у «все годы» отклонение
  ≈ 0.9 из-за прогноза 0 у ячеек без ДТП).
