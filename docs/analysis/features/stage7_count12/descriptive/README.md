### Сверхдисперсия: сырые счёты без модели (рис. 1б, 1в; `overdispersion.csv`)

| срез | дисперсия / среднее | k (метод моментов) |
|---|---|---|
| между ячейками, по годам 2015–2025 | 2.8–3.8 (снижается: 3.77 в 2015 → 2.80 в 2025) | 0.13–0.18 |
| все ячейко-годы вместе | 3.26 | **0.149** |
| внутри ячейки по годам, ожидание = эффект ячейки × эффект года | **1.08** | **≈ 53** |

Формулы:
- k = μ² / (σ² − μ);
- для среза «внутри ячейки» k = Σμ² / Σ[(y − μ)² − μ], где μ = среднее ячейки × (ДТП года / среднее по годам);
  дисперсия на степень свободы дана с поправкой на 4 296 + 10 оценённых эффектов.

Вывод. «Сырая» сверхдисперсия огромна (k ≈ 0.15), но почти вся она приходится на **различия между ячейками**.
Если известен уровень ячейки, её счёт по годам почти пуассоновский: φ = 1.08, k ≈ 53. Отсюда ориентир для
агента A. Если признаки объясняют уровень ячейки хорошо, k на остатках модели будет ближе к 53, чем к 0.15.
Каким оно окажется между этими значениями, покажет доля межъячеечной разницы, объяснённая моделью.

  - Половина очагов каждого года — новые.
  - Из-за порога число очагов чувствительно к уровню. При падении ДТП на 13 % в 2024–2025 гг. очагов стало

**Сверка с METHODOLOGY 5.1.1** (скользящие окна 12 мес., 8 387 ячеек bbox). Расчёт **воспроизведён**.

- Срабатывание правил — 4 741 / 778 / 6 960 против 4 717 / 758 / 6 939.
- Уникальных ячеек 455 (= 455). Персистентность «месяц к месяцу» — 0.890 (= 0.890).
- Окно, начатое в январе, совпадает с календарным годом (проверено).

1. Скользящая даёт 455 ячеек, календарная — 368. Ещё 90 ячеек становятся очагом только в окне, которое

**Оговорка: ячейка H3 — площадь, участок ОДМ — линия 200 м** (`odm_boundary.csv`). Масштаб оценён двумя
способами.
1. **Пары соседних ячеек.** Обе ячейки не очаг, а вместе набирают порог. Таких пар за 11 лет 1 993
   (2 374 ячейко-лет), это больше, чем самих очагов. Пара ячеек — это ≈ 0.2 км² и ≈ 600 м протяжённости,
   поэтому оценка — грубая верхняя граница. Кольцо k = 1 (7 ячеек) ещё грубее: 7 473 ячейко-лет.
2. **Точечный критерий, ближе к ОДМ.** Берётся диск диаметром 200 м вокруг каждого ДТП того же года; порог
   тот же. Диски с общими ДТП объединяются в кластеры. Это не линейный участок одной дороги: диск
   захватывает и пересекающие улицы.
   - За 2015–2025 гг. нашлось **727 таких кластеров**. 298 из них лежат в ≥ 2 ячейках.
   - **691 кластер (95 %)** попадает в ячейку-очаг, **36 (5 %, 0–5 в год) разрезаны** границей ячеек и не
     дают очага ни в одной из них.
   - Обратный эффект сильнее: **325 из 1 105 очагов-ячеек (29 %)** не содержат ни одного 200-метрового
     кластера. В них порог набран ДТП, разбросанными по площади ячейки (≈ 0.1 км², несколько улиц).

Итого: сетка редко теряет компактный очаг. Ячеечный аналог критерия ОДМ **мягче** линейного — примерно
треть ячеек-очагов не была бы участком концентрации по ОДМ.

## Функция для шага 3 (recall очагов ОДМ для модели)

```python
import sys; sys.path.insert(0, "scripts")
from stage7B_descriptive import odm_recall, odm_recall_from_preds, odm_flag

odm_recall(scores, year, fracs=(0.01, 0.05, 0.10))
# scores — pd.Series h3 -> скор (прогноз, сделанный ДО года year), для всех 4 296 ячеек (иначе ValueError),
#          или DataFrame с колонками h3 и score_col="score".
# -> {'year', 'n_cells', 'n_hot', 'recall_top_1pct', 'recall_top_5pct', 'recall_top_10pct'}

odm_recall_from_preds(preds, run_id, split="test")
# preds — таблица *_preds.parquet раннера (split, run_id, seed, h3, year, pred); скор усредняется по сидам;
# строки по годам оценки + 'pooled' (Σ попавших / Σ очагов).
```

- Очаг вычисляет `odm_flag(panel)`: `max(count_type_* без other) ≥ 3` или `count_year ≥ 5`.
- Recall — это `vy.coverages(hot, score)`: доля очагов среди верхних k = max(1, int(n·q)) ячеек. Связи
  учитываются честно, как в метриках 7.4.
- ДИ для pooled-recall даёт `bootstrap_odm_recall(hot_by_year, s_by_year)`: одна выборка ячеек на все годы.
- Проверено: функция совпадает с таблицей ориентиров. На дымовых прогнозах шага 1 у `accidents_prev_3y`
  pooled топ-5 % = 0.726, как в таблице выше.

## Абзац для курсовой

Годовой счёт ДТП в ячейке H3 крайне неравномерен.
- В 84 % ячейко-лет ДТП нет, а 5 % ячеек собирают половину всех ДТП за 11 лет.
- Дисперсия по ячейкам в 3 раза больше среднего (k ≈ 0.15). Почти вся эта сверхдисперсия — различия между
  местами: при известном уровне ячейки её годовые счёты близки к пуассоновским (φ = 1.08).
- Поэтому ранг ячейки складывается из устойчивого «уровня места» и большого годового шума. Корреляция
  рангов между соседними годами — лишь 0.58, но с лагом почти не убывает: 0.50 через 10 лет.
- Отсюда два следствия.
  1. Даже идеальный прогноз уровня места не накроет больше ≈ 75 % ДТП трёхлетнего периода в верхних 10 %
     ячеек. Это потолок, задаваемый случайностью.
  2. История ДТП за много лет — сильный ориентир: 67 % ДТП в топ-10 % (90 % потолка). Ориентир по длине
     магистралей даёт лишь 37 %.
- Ячеечный аналог участка концентрации ДТП по ОДМ 218.6.015-2015 (≥ 3 ДТП одного вида или ≥ 5 любых за
  год) выделяет 1.6–2.8 % ячеек в год. Половина из них меняется каждый год, а число очагов из-за порога
  непропорционально чувствительно к общему уровню аварийности. При снижении ДТП на 13 % в 2024–2025 гг.
  очагов стало на треть меньше.
- Сетка редко разрезает компактный 200-метровый кластер ДТП (5 % случаев). Зато треть ячеек-очагов набирает
  порог за счёт ДТП, разбросанных по нескольким улицам. Поэтому ячеечный критерий следует называть
  аналогом критерия ОДМ, а не самим критерием (проблема изменяемой площадной единицы, MAUP).

## Ограничения

- Ориентиры ранжируют ячейки по истории, которой у новой территории или второго города нет. Это верхняя
  планка «инспектора по статистике», а не конкурент структурной модели.
- Скор ширины СКДФ — с NaN = 0 у 40 % ячеек без паспорта: такие ячейки ранжируются внизу. Ширина без
  заполнения пропусков не сравнивалась.
- Сверхдисперсия «внутри ячейки» оценена с фиксированными эффектами ячейки и года по 11 точкам. Это оценка
  сверху для k, если уровень ячейки меняется во времени (тренд ячейки уходит в «шум»), и снизу, если
  эффекты переобучены. Её задача — порядок величины.
- В снижении ДТП в «тяжёлых» ячейках часть может быть регрессией к среднему: группы отобраны по той же
  истории.
- Очаги размечены по календарному году, ОДМ говорит о «последних 12 месяцах». Скользящая разметка даёт на
  90 ячеек больше (сверка выше). Вид «прочие» (0.7 %) в правило «одного вида» не входит.
- Точечный критерий — диск, а не линейный участок одной дороги, и он считает только ДТП в ячейках с
  дорогами. Перекрёсток как отдельный объект ОДМ не моделировался.
