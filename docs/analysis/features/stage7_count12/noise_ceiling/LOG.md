  - смесь 3 гамм без ограничений выродилась в точку λ = 0 с правдоподобием +3977 (численный артефакт
    gammaln при огромных параметрах) → ограничил |log a|, |log b| ≤ 7; добавил модели с нулевой компонентой
    (λ ≡ 0). Вес нулевой компоненты сошёлся к 0, т. е. «ячеек без риска» данные не требуют. По BIC лучшая —

  - Одна гамма уже хорошо ловит долю нулей (0.602 против 0.598) и хвост (≥ 30 ДТП: 2.8 % против 3.1 %).
  - **Spearman: оракул «строгий порядок по λ» не предел.** На фолдах Spearman оракула (0.57) ниже, чем у
    моделей на факте (0.59–0.61) → самопроверка не прошла. Причина: Spearman — корреляция рангов, а у Y 74–84 %
    нулей (связи). Строгий порядок по λ раздаёт ячейкам с почти нулевым риском разные ранги, а Y у них одинаков,
    и это «тратит» дисперсию рангов скора. Скор со связями, похожими на связи Y (история!), выигрывает: в
    симулированном мире ориентир «сумма симулированной истории» имеет Spearman 0.737 > 0.712 у оракула.
    Огрубление λ до K равных квантильных групп не помогает (0.695–0.712). Помогает «оракул с формой Y»: ранги λ
    переносятся на отсортированную независимую копию Y (те же связи-нули, порядок — по λ): Spearman 0.80 на
    тесте, 0.71–0.72 на фолдах. Предел Spearman = max(строгий, «с формой Y»). С ним самопроверка проходит.
  - Апостериорная прогностическая проверка: в симулированном мире ориентир «сумма истории» даёт топ-10 % 0.700
    (на факте у истории 0.668) — мир модели немного «предсказуемее» реальности (нестационарность риска ячеек).
