### Соглашение о значимости (восстановлено по существующим отчётам)

Пересчитал `reports/road_only_4_0_grade2_delta.csv` из
`reports/road_only_4_0_grade2_seed_runs.csv`. Столбец `two_sigma` в проекте —
это `2·sqrt((sd_A² + sd_B²)/5)`, т.е. удвоенная стандартная ошибка разности
средних двух независимых выборок по 5 сидов (не 2·sd парных разностей и не
2·sd без деления на n). Для сопоставимости с прежними записями использую ту же
формулу. Вердикт: |Δ|/2σ < 1 — «шум»; 1 ≤ |Δ|/2σ < 1.5 — «на границе»
(так в записи Road+Geo Baseline названо отношение 1.02); ≥ 1.5 — «значимо».
Дополнительно в CSV пишу 2·sd парных разностей (по сидам) как справочную колонку.

## 4. Сверка таблицы этапа 1 с фактическими ρ

Для каждого из 27 удаляемых по плану признаков найден ближайший оставляемый.
Числа ревью в целом подтвердились (расхождения ≤ 0.02). Проверка оставшихся 34
признаков на пары ≥ 0.85 нашла то, что план пропустил.

**Отклонение 1 (добавлено удаление).** `minor_to_major_junction_count` ↔
`unsignalized_high_delta_junction_count`: **ρ = 0.978** — оба по плану оставались.
Плюс `junction_count` ↔ `minor_to_major_junction_count` ρ = 0.908. Это
неучтённая пара ≥ 0.9, правило «одна величина — один признак» требует убрать
один. Оставлен `unsignalized_high_delta_junction_count`: важность выше (0.96,
ранг 38, против 0.66, ранг 46), одиночный AUC выше (0.822 против 0.819), а по
ревью он — честная заготовка `driveway_count` из этапа 2. Название
`minor_to_major_*` к тому же вводит в заблуждение (это «любая пара разных
классов без светофора», 73 % — пары с service).

**Отклонение 2 (заменён оставляемый признак).** Тупики: ρ(`dead_end_count`,
`dead_end_density_per_km`) = **0.846** — чуть ниже порога 0.85 (в ревью 0.859).
Оба признака — одна величина в двух формах (count и density одного объекта),
поэтому одна из них уходит по-прежнему. Но план оставлял density, а я оставил
**count**:
- во всех остальных парах count/density этого же этапа (перекрёстки,
  `minor_to_major`, `class_delta`) план сам оставляет count;
- PLAN.md, этап 4: «не держать count и density одновременно (ячейки
  равноплощадные, count уже плотность на км²) — по умолчанию оставлять count»;
- делитель density включает service и нестабилен на коротких ячейках
  (max 631/км у ячеек с 30 м дороги, ревью B8);
- одиночный AUC count 0.711 против 0.578 у density.
Риск: у density важность выше (2.76, ранг 11, против 0.97). Если абляция покажет
просадку, это первый кандидат на возврат.

**Подтверждено без изменений.** Остальные пары: `lanes_tagged_share` 0.956 с
`lanes_mean_weighted`; `road_way_count` 0.933, `lane_meters_estimate` 0.966 с
длиной; `maxspeed_mean_weighted` −0.978 с `road_share_service`; legacy 0.980;
class_delta density 0.997; junction density 0.930; degree max 0.943; class_delta
mean 0.934; signalized class_delta 0.922 с `traffic_signal_count` (+95 % нулей);
sharp_turn density 0.968 / count 0.896 с share; turn_event 0.931 с плотностью
сегментов; segment count 0.906 с длиной, mean 0.891 с медианой, density 0.892 с
`short_segment_share`; asphalt share 0.918 с length. Не-дубликаты, удаляемые по
другим основаниям: `maxspeed_tagged_share` (полнота OSM, max ρ 0.651),
`maxspeed_max` (4 уникальных значения, ρ −0.70 с service), `major_road_share`
(композиция, max ρ 0.745), мёртвый груз (5 признаков с 98–99.4 % нулей,
max ρ ≤ 0.32).

**Оставшиеся пары 0.80–0.90 внутри итогового набора** (оставлены сознательно,
их честно разводит этап 2/4): `junction_count`–`unsignalized_high_delta` 0.890,
`class_delta_max`–`unsignalized_high_delta` 0.863, `road_curvature_max`–
`sharp_turn_share` 0.837, `junction_degree_mean`–`three_way_junction_count` 0.825,
`road_length_total_m`–`junction_count` 0.812, `road_curvature_mean_weighted`–
`curvature_deg_per_km` 0.811. Ни одной пары ≥ 0.9 не осталось.

**Сохранён с оговоркой** `lanes_mean_weighted`: 70.5 % нулей = «тег не стоит»;
после удаления `lanes_tagged_share` пара 0.956 закрыта, перекодировка 0 → NaN —
этап 3.

Итог: 27 по плану + 1 (`minor_to_major_junction_count`), замена density → count
у тупиков: **61 → 33**.

## 6. Основная абляция: 61 против 33

Скрипт `scripts/run_road_geo_v2_prune_experiments.py` (каркас — grade-скрипт;
каппы p99 для каждого варианта свои, по train; варианты задаются флагом,
строки варианта в `reports/road_geo_v2_prune_seed_runs.csv` перезаписываются).

```text
venv/bin/python scripts/run_road_geo_v2_prune_experiments.py \
  --variants road_geo_baseline,road_geo_v2_prune
```

Один сид ≈ 47 с (8 ядер), вариант из 5 сидов ≈ 4 мин. Бейзлайн, seed 42:
ROC-AUC 0.908056, PR-AUC 0.198881, p@1 % 0.3072 — бит в бит со штатным прогоном,
т.е. каркас абляции воспроизводит рецептуру.

Фигуры и разности: `scripts/plot_road_geo_v2_prune.py` (matplotlib, без seaborn;
палитра: синий — оставлен/бейзлайн, оранжевый — удалён/prune; тепловые карты —
расходящаяся синий ↔ красный с серой серединой).

Результат (≈ 7 мин на оба варианта; prune обучается быстрее — 37 с на сид):

| метрика | 61 | 33 | Δ | 2σ | вердикт |
|---|---|---|---|---|---|
| ROC-AUC | 0.907851 ±0.000230 | 0.908040 ±0.000223 | +0.000188 | 0.000287 | шум |
| PR-AUC | 0.198550 ±0.000595 | 0.199696 ±0.000308 | **+0.001147** | 0.000599 | значимо (1.9×) |
| precision@1 % | 0.3100 ±0.0070 | 0.3125 ±0.0051 | +0.0026 | 0.0077 | шум |
| recall@1 % | 0.1327 ±0.0030 | 0.1338 ±0.0022 | +0.0011 | 0.0033 | шум |
| recall@5 % | 0.4426 ±0.0015 | 0.4421 ±0.0022 | −0.0005 | 0.0024 | шум |

- Просадки больше 2σ нет ни по одной метрике → поиск виновника (возврат групп
  по одной) **не нужен**; по заданию делаю 3 промежуточных варианта для графика вклада групп.
- Пять строк бейзлайна совпали с `road_only_4_0_grade2` из
  `reports/road_only_4_0_grade2_seed_runs.csv` с точностью 0.0 (все метрики) —
  каркас полностью воспроизводит прежние прогоны.
- Замечание к старой записи: в таблице Road+Geo Baseline у ROC-AUC указано
  sd 0.000389, а по сырым прогонам sd = 0.000230 (их же 2σ = 0.000325 считалось
  от верного sd). Опечатка в тексте, на выводы не влияет; в новой записи — верное число.
- Оговорка к PR-AUC: по соглашению проекта (ст. ошибка разности средних) Δ = 1.9·2σ,
  «значимо». Более строгая парная оценка (2·sd разностей по одинаковым сидам) =
  0.0014 > Δ. Формулировка для текста: «PR-AUC не ухудшился, есть признаки
  небольшого улучшения» — не «вырос».
- Удалённые 28 признаков несли **35 %** суммарной важности бейзлайна (среднее по
  5 сидам), и эта доля перераспределилась без потери качества.
- `dead_end_count` в prune — ранг 17 (важность 2.83 ≈ прежние 2.76 у density):
  замена density → count информацию не потеряла.
- Повтор этапа 0 на итоговом наборе (`feature_dedup_report.py --feature-set
  road_geo_v2_prune --prefix road_geo_v2_prune`): пар ≥ 0.85 осталось две, обе
  < 0.9 и обе про `unsignalized_high_delta_junction_count` (0.890 с
  `junction_count`, 0.863 с `class_delta_max`) — блок перекрёстков переделывает этап 2.
