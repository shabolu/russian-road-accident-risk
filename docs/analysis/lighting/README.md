# Ночная освещённость (VIIRS) — почему не в кассу

**Вопрос.** Добавляет ли ночная яркость ячейки (VIIRS VNL, nW/cm²/sr) качества
road-only 4.0? Важно ли сопоставлять яркость с годом строки?

**Ответ: нет и нет.** Запись: `EXPERIMENTS.md` →
«2026-09-15 - Road-Only 4.0 + ночная освещённость (VIIRS)».

| вариант | ROC-AUC | PR-AUC | prec@1% |
|---|---|---|---|
| road-only 4.0 | 0.907737 | 0.197933 | 0.3026 |
| + `ntl_alltime` | 0.908143 | 0.198203 | 0.3074 |
| + `ntl_year` | 0.908482 | 0.198296 | 0.3017 |

Прирост ROC формально значим (2σ ≈ 0.0002), но это 4–7 десятитысячных; PR-AUC — в
шуме; по prec@1% порядок вариантов переворачивается. При этом CatBoost поставил
признак на **1-е место по важности** — он перехватывает информацию плотности дорог,
а не добавляет новую.

**Почему.** Ночные и дневные ДТП происходят в одних ячейках: Spearman между
половиной ночных и половиной дневных 0.555 при внутригрупповых 0.557 / 0.581.
Отдельной «ночной географии риска» нет — признаку нечего объяснять.

**Что осталось полезного.** VIIRS **валидирован как измеритель освещения** по
полю `light_type` карточек ДТП: AUC 0.813 при определении «освещение отсутствует»
против 0.572 у тега OSM `lit`; разделение сохраняется внутри квинтилей плотности
дорог. Попутно найден и убран сломанный признак `lit_road_length_m`
(тег `lit` есть у 5.1% сети; отсутствие трактовалось как «не освещено») —
удаление подняло PR-AUC на +0.0011.

**Ограничения источника.** Датчик слеп ниже 500 нм → замена натриевых ламп на
светодиоды читается как «потемнение» (p90 по городу упал 24.6 → 15.9 за 2015–2025
при росте суммы 77.9 → 115.3). Пятно захвата ~742 м, не 30 м. Единой версии на
2012–2025 нет (v2.1 / v2.2, стык 2021→2022).
