## analysis/ — направления

| папка | вопрос | вердикт |
|---|---|---|
| `analysis/lighting/` | даёт ли ночная освещённость (VIIRS) прирост модели | **нет**, но признак валидирован как измеритель освещения |
| `analysis/seasonality/` | нужны ли снег/погода/сезон как признаки | **нет**: цель не имеет сезонного пространственного измерения |
| `analysis/terrain/` | даёт ли продольный уклон дорог (DEM) прирост | **да**, в верхе ранжирования; 2 признака из 6 вошли в **road+geo baseline** |
| `analysis/skdf/` | что такое ФГИС СКДФ и что из него брать; инвентарь 259 слоёв в `LAYERS.md` | паспортные атрибуты — да, `traffic` — с оговорками |
| `analysis/features/` | ревью всех 61 признака бейзлайна: что реально считают, дубликаты, кодировка, кандидаты в прокси-признаки | около половины признаков измеряют свойства карты OSM, а не дороги; план пересчёта перекрёстков, покрытия, сегментации |
| `analysis/exposure/` | **где взять интенсивность движения** — сводка всех источников и порядок действий | главная открытая дыра; 2 бесплатных шага сейчас + 2 запроса по 8-ФЗ |
| `analysis/exposure/LITERATURE_REVIEW.md` | какие прокси экспозиции из открытых данных (класс дороги, betweenness, POI, остановки, здания, население, NTL) работают в литературе; утверждения с вердиктами — `literature_claims.csv` | класс дороги — сильнейший прокси машин; голый betweenness слаб, нужны вес по времени и буфер; для пешеходов — POI и площадь по назначению, не центральность и не население |

Каждая папка: `README.md` с вопросом, ответом, ключевыми числами и ссылкой на
запись в `EXPERIMENTS.md`, плюс фигуры.
