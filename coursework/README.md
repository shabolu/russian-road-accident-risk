# Курсовая работа

Шаблон: csit-sgu/latex-template, опция `coursework`.
Сборка: Overleaf (загрузить папку) или локально `pdflatex -shell-escape main && bibtex main && pdflatex -shell-escape main ×2`.
`preamble.sty` подключает `minted` — нужен `-shell-escape` и Pygments.

Локальная сборка через установленный Tectonic (из папки `coursework`):

```sh
tectonic -Z shell-escape --keep-logs --keep-intermediates --outdir build main.tex
```

Результат: [build/main.pdf](build/main.pdf). Папка сборки исключена из Git.
